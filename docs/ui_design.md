# UI design

MindFlow uses an original quiet teal identity: seed #24786B, warm light background #F6F7F3, generous rounded cards, spacious page headings, restrained tonal emphasis and Material 3 controls. Dark colors derive from the same seed. Spacing scale: 4, 8, 12, 16, 24, 32. Content max width 1200. Desktop sidebar breakpoint 800; compact layouts use six-destination navigation and wrapped controls.

Tasks are the launch view. All views share the task editor and canonical records. Quick add remains in the shell; Ctrl/Cmd+N creates a task, Ctrl/Cmd+K opens search. Theme/language controls and sync attention are visible. Form validation, destructive confirmations, loading/error states and semantic Material controls are mandatory. EN/VI labels are incrementally implemented; untranslated strings are tracked in status.
